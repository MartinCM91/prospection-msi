Aide et mode d'emploi

Documentation interne pour assurer la continuité de l'outil.

1. Choix de produit

À la connexion, choisissez le produit (MSI ou Formation LEAN). Le sélecteur en haut à droite permet de changer à tout moment.

2. Tableau de tâches

5 colonnes : Leads → Phoning → RDV Qualification du besoin → Rédaction de l'offre → Avancement (Négociation/Signé/Perdu). La case "Terminée" sur une carte la marque comme close. Les tâches en retard apparaissent en rouge.

3. Suivi hebdo

Saisie hebdomadaire des actions par commercial. La section "Tâches ouvertes à T0 vs T+1" identifie les tâches qui restent ouvertes d'une semaine sur l'autre.

4. Calendrier

Le calendrier principal liste les sources de prospection. En dessous, le calendrier MSI affiche les grandes dates (revue projet, intervention client). Bouton ⛶ pour le plein écran. Bouton "+ Source" pour ajouter une nouvelle source ou sous-source.

5. Export Excel

Bouton "📊 Export Excel" en haut à droite. Génère un fichier .xlsx avec plusieurs onglets : tâches, suivi hebdo, événements, objectifs, KPI.

6. Remise à zéro

Dans l'onglet Objectifs, chaque section a un bouton 🔄 qui efface les valeurs cibles (les données réalisées sont préservées).

7. Maintenance technique

Code sur GitHub. Base sur Supabase. Hébergement Netlify ou Cloudflare Pages.
