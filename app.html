Aide et mode d'emploi

Cette page documente l'utilisation de l'outil pour assurer sa continuité dans le temps. Lisez-la en entier la première fois.

1. À quoi sert cet outil

Cet outil sert à piloter la prospection commerciale de l'offre MSI (Mission Sectorielle d'Ingénierie) de l'ICAM. Il permet de centraliser les actions des commerciaux, suivre les opportunités d'affaires, et mesurer l'atteinte des objectifs annuels.

Trois utilisateurs principaux : les commerciaux qui saisissent leur activité hebdomadaire et leurs affaires, le responsable de la prospection qui suit les KPI globaux, la direction qui consulte le tableau de bord pour les revues.

2. Comment commencer (paramétrage initial)

  1. Créer son compte via le bouton Inscription sur la page d'accueil. Renseigner prénom, nom, email et mot de passe.
  2. Définir les objectifs annuels dans l'onglet Objectifs. Saisir le CA cible et le nombre de MSI cible pour l'année en cours, puis détailler par période MSI (2526B, 2627A).
  3. Définir les objectifs par source dans le même onglet. Ces objectifs servent au pilotage de la prospection événementielle.
  4. Inviter les autres commerciaux à créer leur compte. Une fois inscrits, leur ligne apparaîtra automatiquement dans le Suivi hebdo.

3. Utilisation hebdomadaire (commerciaux)

  1. Ouvrir l'onglet Suivi hebdo chaque vendredi.
  2. Sélectionner la semaine en cours.
  3. Saisir pour chaque type d'activité le nombre d'actions effectuées : appels et contacts, RDV effectués, propositions envoyées.
  4. La sauvegarde est automatique dès qu'une valeur est modifiée.

4. Gestion des affaires

Chaque opportunité commerciale est une affaire. Le cycle de vie d'une affaire passe par 6 états successifs :

  1. Qualification : premier contact, besoin à clarifier.
  2. Expression de besoin : le besoin du client est connu et documenté.
  3. Proposition envoyée : devis officiel envoyé.
  4. Négociation en cours : échanges sur les conditions ou le prix.
  5. Contrat validé : affaire gagnée (compte dans le CA signé).
  6. Contrat refusé : affaire perdue (renseigner la raison).

Le niveau de confiance est une probabilité entre 0 et 1 que l'affaire se signe. Le montant pondéré (montant × confiance) donne le CA en cours réaliste.

5. Lecture du tableau de bord

Le tableau de bord se met à jour automatiquement à partir des données saisies. Les indicateurs clés :

  • CA en cours : somme des montants pondérés des affaires non encore signées. C'est le CA réaliste qu'on peut espérer.
  • CA signé : somme des montants des affaires en état "Contrat validé".
  • Taux RDV → Proposition : combien de RDV débouchent sur une proposition envoyée.
  • Taux Proposition → Signé : combien de propositions deviennent des affaires signées.
  • Performance par période MSI : compare l'objectif et le réalisé pour chaque semestre.

6. Onglets Calendrier et Événements

Ces onglets servent à planifier la prospection événementielle (JPO, salons, webinaires, etc.). Le calendrier croise sources et mois sur l'année, et chaque case vide permet de créer un nouvel événement directement.

7. Maintenance technique

L'application repose sur trois services gratuits :

  • GitHub : héberge le code source. Pour modifier l'application, éditer les fichiers index.html, app.html, app.js, style.css, config.js.
  • Supabase : héberge la base de données et l'authentification. Pour ajouter des champs ou des tables, utiliser le SQL Editor. Pour gérer les utilisateurs, aller dans Authentication.
  • Netlify : héberge le site web. Toute modification du code sur GitHub déclenche un re-déploiement automatique en 30 secondes.

Les sauvegardes Supabase sont automatiques sur 7 jours en plan gratuit. Pour une sauvegarde manuelle, exporter les données depuis l'onglet Database de Supabase.

8. Évolutions à prévoir

Cet outil est conçu pour évoluer. Les pistes prévues :

  • Gestion fine des droits (admin vs commercial).
  • Ajout des offres Lean Management et Formation Continue.
  • Module Comptes prioritaires avec priorité A/B/C (Safran, Aalberts, Equans...).
  • Import automatique depuis l'Excel KPI existant.
  • Export Excel des données pour analyses externes.

9. Qui contacter en cas de problème

Si une erreur s'affiche ou une fonctionnalité ne marche pas, ouvrir la console du navigateur (touche F12, onglet Console) pour voir le message d'erreur précis. La plupart des problèmes viennent d'une mauvaise configuration Supabase (clés API dans le fichier config.js).

Pour toute modification de l'outil, contacter l'équipe technique de l'ICAM ou faire appel à un développeur web (compétences requises : HTML, JavaScript, SQL).
