Aide et mode d'emploi

Documentation interne pour assurer la continuité de l'outil.

1. À quoi sert cet outil

Pilotage de la prospection commerciale ICAM. À la connexion, choisissez le produit (MSI ou Formation LEAN). Changeable à tout moment via le sélecteur en haut à droite.

2. Tableau de tâches — 5 colonnes

5 colonnes : 1. Recherche de leads, 2. Phoning, 3. Expression de besoin, 4. Suivi des propales, 5. Avancement.

Glissez-déposez les cartes. Cliquez sur une carte pour modifier. La section Avancement (montant, statut) apparaît seulement en colonne 5.

3. Checklists de préparatifs

Chaque source dispose d'une checklist de préparatifs. Pour y accéder :

  • Onglet Sources : voir toutes les sources et leurs checklists.
  • Calendrier : icône 📋 à côté de chaque source.
  • Événements : sur la fiche événement, lien vers la checklist de sa source.

Les checklists sont éditables. Cochez les actions au fur et à mesure. Pré-remplies pour Meeting-Ingé, JPO, Webinaires, Salons, Réseau pro, Alumnis selon le fichier Excel ICAM.

4. Événements enrichis

Un événement peut désormais :

  • S'étaler sur plusieurs jours (date début + date fin)
  • Être de type Intérieur (JPO, FAIM, CIE) ou Extérieur (salons, webinaires partenaires)
  • Avoir un lieu structuré (libre + ville + code postal + adresse)
  • Avoir plusieurs objectifs (contacts, RDV, propales) avec résultats séparés

5. 6 KPI du plan d'action

Sur le tableau de bord : Contacts, RDV qualifiés, Propales rédigées, En cours (entre RDV et propale), Offres signées, Offres perdues. Les valeurs cibles sont paramétrables dans l'onglet Objectifs.

6. Maintenance technique

Code sur GitHub. Base sur Supabase. Hébergement Netlify ou Cloudflare Pages (alternative gratuite illimitée).
