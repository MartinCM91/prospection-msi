Aide et mode d'emploi

Documentation interne pour assurer la continuité de l'outil dans le temps.

1. À quoi sert cet outil

Pilotage de la prospection commerciale MSI de l'ICAM. Trois utilisateurs principaux : commerciaux (saisie quotidienne), responsable prospection (suivi global), direction (revue tableau de bord).

2. Plan d'action MSI (les 8 étapes)

Chaque opportunité commerciale est une "cible MSI" qui suit 8 étapes dans l'ordre :

  1. Recherche de leads : sourcing entreprises, alumnis, salons, réseaux institutionnels.
  2. Phoning : appels anciens clients, leads identifiés, campagnes de prospection.
  3. Expression de besoin : RDV physique, utilisation du Smart Diag pour clarifier le besoin.
  4. Communication : LinkedIn, presse, réseaux sociaux, com client.
  5. Financement : montage financier de la proposition.
  6. Paiement : suivi du paiement après signature.
  7. CRM : saisie et maintenance du dossier dans le CRM.
  8. Résultats / Signé : bilan final, contrat signé.

Dans l'onglet Plan d'action, chaque cible MSI est une carte que vous faites avancer d'étape en étape. Cliquez sur une carte pour voir le détail et ajouter des actions précises (qui fait quoi, pour quand).

3. Sources de prospection

Les sources sont organisées par groupes pour plus de clarté :

  • RÉSEAUX (institutionnels) : Alumnis ICAM, Grand Paris Sud, ESF, ESSI, Réseau Entreprendre 77/91, CCI 77/91, AEIV, Maîtres d'apprentissage.
  • RÉSEAU PRO : contacts personnels (chaque commercial enrichit son carnet).
  • ÉVÉNEMENTS : JPO ICAM, Salons (Global Industrie, Convention Affaires GPS, Tech Innove, Tech Industrie, Multi-Ingé), Webinaires.
  • DIGITAL : LinkedIn.
  • FIDÉLISATION : Anciens clients à relancer.

Note importante : Smart Diag n'est PAS une source de leads. C'est un outil utilisé à l'étape 3 (Expression de besoin) pour qualifier un prospect déjà identifié.

4. Entreprises et contacts

Une entreprise peut avoir plusieurs contacts (commercial, technique, décideur) et plusieurs cibles MSI en cours. Les entreprises sont classées par priorité :

  • Priorité A : fort potentiel immédiat (Safran, Aalberts, ELIS, Ministère Armées, Nexson, MKS).
  • Priorité B : à développer / qualifier (Equans, Les Ateliers Autrement, SADE, Suez, CRAMIF).
  • Priorité C : vivier à construire.

5. KPI hebdomadaires et alertes

Le tableau de bord affiche en temps réel :

  • RDV qualifiés cette semaine (objectif paramétrable, par défaut 4). Affiche en rouge si en retard.
  • Propales rédigées ce mois (objectif paramétrable, par défaut 8). Affiche en rouge si en retard.
  • Contrats signés vs objectif MSI annuel.

6. Maintenance technique

L'application repose sur trois services gratuits :

  • GitHub : héberge le code (index.html, app.html, app.js, style.css, config.js, logo-icam.png).
  • Supabase : base de données et authentification.
  • Netlify : hébergement web. Toute modification GitHub déclenche un re-déploiement auto en 30s.

Si Netlify atteint sa limite gratuite (100 Go bande passante/mois), migrer vers Cloudflare Pages (illimité). Sauvegardes Supabase automatiques sur 7 jours.

7. En cas de problème

Ouvrir la console du navigateur (F12 → onglet Console) pour voir les erreurs. La plupart des problèmes viennent de la configuration Supabase dans config.js.
