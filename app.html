Aide et mode d'emploi

Documentation complète de l'outil de prospection commerciale ICAM.

1. Choix de produit

À la connexion, choisissez MSI ou Formation LEAN. Changeable via le sélecteur en haut à droite. Toutes les données sont filtrées par produit.

2. Tableau de tâches — 5 colonnes

1. Leads (Nb contacts) → 2. Phoning (Nb appels + Nb RDV à obtenir) → 3. RDV Qualification du besoin (Nb besoins identifiés + retenus) → 4. Rédaction de l'offre (Nb propositions réalisées + retenues) → 5. Avancement (Négociation/Signé/Perdu + Montant + Date signature + Période MSI).

Période MSI : chaque contrat signé est rattaché à une période MSI (2526B, 2627A...) pour savoir à quelle période il compte, même s'il est signé pendant une autre. Les contrats signés sans date de signature apparaissent comme "⏳ En attente de date".

Glisser-déposer : quand vous déplacez une carte vers une autre colonne, la modale s'ouvre automatiquement pour remplir les champs de la nouvelle étape.

3. Suivi hebdomadaire + Revue

Saisie par commercial des 4 activités : Appels/Contacts, RDV planifiés, RDV qualifiés, Offres envoyées. Section "Tâches ouvertes T0 vs T+1" : identifie les tâches qui devaient être faites cette semaine. En dessous : Revue (mensuel/trimestriel/période MSI) avec KPI, comparaison vs période précédente, et taux de conversion.

4. Calendrier

Calendrier annuel par source avec icône 📋 pour les checklists de préparatifs. Ligne 🏁 Jalons MSI : icônes spécifiques (📊 Revue, 🎯 Intervention client, 🎤 Soutenance, 📦 Livrable, 👥 Réunion). Zoom mensuel : cliquez sur 🔍 à côté du mois pour voir le calendrier détaillé jour par jour + liste chronologique. Plein écran : bouton ⛶. + Source : créez une nouvelle source directement depuis le calendrier.

5. Export Excel

Bouton "📊 Export Excel" en haut à droite. Génère un fichier .xlsx avec 9 onglets : Tâches, Suivi hebdo, Événements, Objectifs événements, Objectifs périodes, KPI, Objectifs sources, Checklists, Jalons MSI. Chaque onglet a un en-tête clair et les données sont structurées.

7. Objectifs et remise à zéro

Objectifs par période (CA + nombre), 6 KPI cibles, objectifs contacts par source. Chaque section a un bouton 🔄 RAZ pour remettre les valeurs cibles à 0 (les données réalisées sont conservées).

8. Maintenance technique

Code source : GitHub. Base de données : Supabase (PostgreSQL). Hébergement : Netlify (déploiement automatique à chaque push). Pour modifier le code : éditez les fichiers sur GitHub, attendez 30 secondes, puis rechargez avec Ctrl+F5.
