Aide et mode d'emploi

Documentation interne pour assurer la continuité de l'outil.

1. À quoi sert cet outil

Pilotage de la prospection commerciale MSI ICAM. Commerciaux saisissent leur activité, responsable suit les KPI, direction consulte le tableau de bord.

2. Plan d'action MSI — les 8 étapes

Chaque opportunité commerciale est une "cible MSI" qui suit 8 étapes :

  1. Recherche de leads : sourcing entreprises, alumnis, salons, réseaux.
  2. Phoning : appels anciens clients, leads identifiés, campagnes.
  3. Expression de besoin : RDV, Smart Diag.
  4. Communication : LinkedIn, presse, réseaux sociaux.
  5. Financement : montage financier.
  6. Paiement : suivi du paiement.
  7. CRM : maintenance du dossier.
  8. Résultats / Signé : contrat signé.

Pour faire avancer une cible, glissez-déposez la carte d'une colonne à l'autre, ou cliquez dessus pour modifier l'étape dans le formulaire.

3. Sources de prospection

Hiérarchie des sources :

  • Réseau pro (parent) : Grand Paris Sud, ESF, ESSI, Réseau Entreprendre 77/91, CCI 77/91, AEIV.
  • Alumnis : contacts via le réseau alumni ICAM.
  • Salons (parent) : Global Industrie, Convention Affaires GPS, Tech Innove, Tech Industrie, Multi-Ingé.
  • Événements : JPO ICAM, Webinaires.
  • Digital : LinkedIn.
  • Fidélisation : Anciens clients.
  • Réseau ICAM : Maîtres d'apprentissage.

Smart Diag n'est PAS une source de leads. C'est un outil utilisé à l'étape 3 (Expression de besoin) pour qualifier un prospect.

4. Entreprises et contacts

Une entreprise = plusieurs contacts possibles, plusieurs cibles MSI possibles. Priorités :

  • A : fort potentiel immédiat (Safran, Aalberts, ELIS, Ministère Armées, Nexson, MKS).
  • B : à développer (Equans, Les Ateliers Autrement, SADE, Suez, CRAMIF).
  • C : vivier à construire.

5. KPI hebdomadaires et alertes

Les 3 KPI prioritaires en haut du tableau de bord :

  • RDV qualifiés cette semaine : passe en vert si objectif atteint, rouge sinon.
  • Propales rédigées ce mois : idem.
  • Contrats signés : vs objectif MSI annuel.

Les objectifs sont paramétrables dans l'onglet Objectifs (par défaut 4 RDV/semaine et 8 propales/mois).

6. Maintenance technique

L'application repose sur 3 services gratuits : GitHub (code), Supabase (base de données et auth), Netlify (hébergement).

Si Netlify atteint sa limite (impossible pour cet usage), migrer vers Cloudflare Pages. Sauvegardes Supabase auto sur 7 jours.

7. En cas de problème

F12 → onglet Console pour voir les erreurs. La plupart viennent de la config Supabase dans config.js.
